Price Check – Compare Prices via Webhook

A Chrome extension that sends the product page you're viewing to your own AI assistant's webhook, which looks for a lower price at other stores and replies in your assistant's chat. Works with Grok Bot webhook routines.

  • Check price: a quick table of cheaper current offers, with links.
  • Full check: also price history, reviews, return policies, shipping and coupons.
  • Reads the page only when you click. Sends data only to the webhook you set up. Collects nothing.
